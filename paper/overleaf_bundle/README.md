# Overleaf Bundle

Upload the contents of this folder to a fresh Overleaf project.

Expected main file:
- `forecastbench_sim.tex`

Included:
- `forecastbench_sim.bib`
- `icml2026_template/` style files required by the paper
- `figures/` with all images and generated table `.tex` inputs used by the main paper and appendix

If Overleaf does not auto-detect the main file, set it to `forecastbench_sim.tex` in the project settings.
