# ForecastBench-Sim Workshop Draft

This directory holds draft-planning material and the official ICML 2026
LaTeX template for the ICML Forecasting Workshop submission.

## Files

- `workshop_outline.md` - current paper plan, figure plan, word budget,
  and writing instructions.
- `icml2026_template/` - ICML 2026 LaTeX style files downloaded from the
  official ICML author-instructions page.

## Format Notes

The ICML 2026 main-conference style files allow an 8-page main body, but
the Forecasting Workshop call supplied for this project limits submissions
to 4 pages excluding references and appendix. Use the ICML template but
keep the workshop draft to 4 main-text pages.

Source checked: https://icml.cc/Conferences/2026/AuthorInstructions
